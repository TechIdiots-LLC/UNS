 Change Log
v3.1.0 (2026-08-01)
  • Client groups: a named collection of screens with its own URL list, which either adds to each member's rotation or replaces it for a takeover. A screen can belong to several groups at once.
  • Emergency mode can now be aimed at one group or one client instead of every screen. The global switch is unchanged and still overrides everything.
  • Emergency mode expires on its own, using the alert's own expiry where it has one, so displays are no longer stranded on an alert if the monitor stops running
  • Alert routing: rules send an incoming CAP alert to particular groups or clients, matching on category, severity, area description or geocode (SAME/FIPS/UGC). With no rules configured the monitor behaves exactly as before.
  • A test suite that runs on PHP 7.4 through 8.4 in CI
  • Fixed emergency mode serving nothing at all on a fresh install, and a rotating display being able to show the same page twice in a row
v3.0.0 (2026-07-31)
  • Pages are rendered with Smarty templates instead of HTML built inside PHP, and output is escaped by default
  • Runs on PHP 7.4 through 8.x
  • New emergency alert monitor (Scripts/EmergencyMonitor) that understands CAP as well as RSS, runs on any platform, and can publish the alert text straight to displays. Replaces the Windows-only Rave RSS task.
  • Emergency monitor settings are configured from UNS Options and stored in the database
  • Installer hardening: it checks everything it needs up front, keeps the database and template cache out of the web root where possible, and creates the database and admin accounts with randomised names and passwords
  • Any internal user can now log in, the built-in admin account name is configurable, and you can no longer lock yourself out by removing or disabling the last administrator
  • Fixed custom message wrapper flags being applied to the wrong message, an options page that could not be saved on SQLite, and a number of smaller bugs
v2.0.0 (2026-07-31)
  • PHP 8 compatibility (was written for PHP 5)
  • Security hardening: SQL queries converted to prepared statements, a session-cookie privilege-escalation bug fixed, command injection and arbitrary file write fixed in the DB backup/restore feature, and passwords upgraded from md5() to password_hash()
  • Database portability: MySQL, Microsoft SQL Server, and SQLite are all supported via PDO, selectable during install
  • Chrome extension modernized to Manifest V3
v1.0 (2010-10-04)
  • Active Directory based authentication
  • Allows multiple client computers with separate list of urls
  • Emergency messages. Easily set a message on all client computers in the event of an emergency. This overrides the clients standard lists.
  • Create quick custom pages. These can be used in the client url list or the emergency url list
  • Copy URLs from on client to another
  • Save a list of URLs for future use
  • RSS Feed Support, choose max number of feeds to view in a page.
